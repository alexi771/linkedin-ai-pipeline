# LinkedIn на ИИ-агентах

Навыки для Claude Code, которые ведут LinkedIn от пустого профиля до регулярных постов. Два пайплайна:

1. **Запуск** (`linkedin-launch`): от профиля до первого поста.
2. **Контент на ботах**: идеи из X, посты из голосовых, лид-магниты. Собран по образцу André Nogueira (10 ботов, каждый делает один шаг).

Здесь только методика и навыки. Личных данных, черновиков и собранных постов нет.

## 1. Запуск LinkedIn с нуля: `linkedin-launch`

Агент ведёт человека по шагам и после каждого шага сохраняет файл:

0. Файл фактов о себе. Всё, что потом пишется о человеке, берётся только оттуда.
1. Точка А. Аудит профиля, аналитика за 7 дней и то, с кем LinkedIn путает человека. Старый профиль сохраняется.
2. Аудитория, язык, рынки.
3. 10 вариантов позиционирования. Вариант показывается, только если под ним есть факт из файла.
4. Решение с датой. Причину записывают словами самого человека.
5. Мониторинг 10 похожих профилей: статус каждого, главный образец, проекты ниши.
6. Тексты профиля. В браузер вносятся только после «да».
7. Проверка источников в первоисточниках.
8. План постов на 2 недели и правила постов.
9. Первый пост по формуле: миф → первоисточник → цифры → вывод для клиента → вопрос. Публикуется только после «да».
10. Замеры через 24 часа и 7 дней, затем сравнение с точкой А.

## 2. Пайплайн контента на ботах

Образец: пост André Nogueira от 22.10.2026 (https://lnkd.in/p/eS8sRXNX), где 10 ботов на Grok ведут LinkedIn.

| # | Бот | Что делает | Навык здесь |
|---|---|---|---|
| 1 | Swipe File Scout | Каждое утро берёт посты из подборки в X и оставляет те, что сильно выше нормы автора | `x-swipe-scout` |
| 2 | Trend Bot | Раз в неделю ищет темы, которые повторяются у 3+ авторов X. В LinkedIn они приходят через несколько недель | `x-trend-bot` |
| 3 | Hook Writer | Пишет 10 первых строк с оценкой | внутри `linkedin-post-draft` |
| 4 | Drafter | Делает черновик из голосового или текста | `linkedin-post-draft` |
| 5 | Anti-Slop Editor | Убирает ИИ-штампы, факты не меняет | `humanizer` |
| 6 | Designer | Инфографика и GIF в стиле бренда | нет |
| 7 | Notion Manager | Раскладывает посты на доске для согласования | нет, вместо него план постов в файле |
| 8 | Lead Magnet Scout | Ищет в LinkedIn посты с раздачей за комментарий, у которых много комментариев | `lead-magnet-scout` |
| 9 | Comment Sorter | Делит комментаторов на покупателей, коллег и остальных | нет |
| 10 | DM Drafter | Пишет сообщения покупателям, отправка только после одобрения | нет |

Порядок работы: X даёт идеи (боты 1-2), из них и голосовых получается пост (3-5), к посту делается картинка (6), пост согласуется (7). Потом идут лиды: магниты, комментаторы, сообщения (8-10).

## Что в репозитории

| Путь | Что внутри |
|---|---|
| `skills/` | 6 навыков Claude Code: `linkedin-launch`, `x-swipe-scout`, `x-trend-bot`, `linkedin-post-draft`, `lead-magnet-scout`, `humanizer` |
| `scripts/` | Скрипты PowerShell для запуска ботов из Планировщика заданий Windows |
| `config/ключи.json` | 20 поисковых ключей для Trend Bot (ниша: ИИ-поиск и GEO, ИИ-контент, стартапы, Китай). Под свою нишу заменить |
| `источники.md` | Проверенные первоисточники про ИИ-поиск и GEO: что в них можно цитировать и чего там нет |
| `уроки.md` | Чему научились по ходу работы: правила постов, приёмы для браузера, ошибки ботов |
| `материалы/` | Заметки по LinkedIn из чужих постов, пересказом: например, какую локацию ставить для поиска работы за рубежом |

## Как поставить

1. Скопировать папки из `skills/` в `~/.claude/skills/`.
2. Создать рабочую папку `~/linkedin/`. Навыки ищут там:
   - `profile.md`: факты о себе, единственный источник для текстов;
   - `README.md`: позиционирование, рубрики, рынки и язык;
   - `проверка-источников.md`: цифры с источниками (образец в `источники.md`);
   - `x-авторы.md`: авторы X для подборки;
   - `тренды/ключи.json`: ключи из `config/`.
3. В X завести приватный List «swipe» и вписать его ссылку в `skills/x-swipe-scout/SKILL.md` вместо `<ссылка на ваш X List>`.
4. Поставить расширение Claude in Chrome и войти в X и LinkedIn в этом браузере. Боты только читают: ничего не лайкают, не комментируют и ни на кого не подписываются.
5. Для запуска по расписанию: положить скрипты из `scripts/` в соответствующие подпапки `~/linkedin/` (`swipe/`, `тренды/`, `лид-магниты/`) и создать задачи в Планировщике заданий. Скрипты рассчитаны на Vivaldi: если стоит Chrome, поменять путь к браузеру.

Ручной запуск: `/linkedin-launch`, `/x-swipe-scout`, `/x-trend-bot`, `/lead-magnet-scout`, `/linkedin-post-draft`.

В образце рынки США и Китай, а российские площадки исключены. Если у вас другие, поправьте их в навыках.
